Things to try once it opens

  • click a part to light up its row in the parts list, or hover a row to find the part
  • H hide, I isolate — for one instance or every copy at once
  • A assembly mode: select whole sub-assemblies and open them
  • D measure between corners, edges and hole centres, with true fitted diameters
  • X section view along any axis, with the cut faces outlined
  • slider explode the assembly, then drag parts aside and snap them back
  • Export your own parts list as Excel, CSV or a printable order sheet

Each file works completely offline too: save it and double-click. The pictures, the 3D model and the parts list are all inside the one HTML file. pictureBOM itself runs on Windows with SolidWorks, or with the free FreeCAD for STEP files — see the README.
